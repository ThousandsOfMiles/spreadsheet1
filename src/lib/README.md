# lib/ —— 和外部世界打交道

原项目这里 19 个文件，管的都是“数据存到哪儿、怎么登录”：

- `puter.js`    所有对 Puter SDK 的调用都收在这一个文件里
- `doc.js`      “当前打开的文档”：保存、自动保存、改名、导出、草稿、版本快照
- `drafts.js`   没存到云上的编辑先留在浏览器里，下次能恢复
- `versions.js` 版本历史
- `recent.js` / `made.js`  首页要显示的“最近打开”
- `session.js`  登录状态（没人/是谁）

骨架里是空的，也**不引入任何云服务**。要接自己的后端（或 localStorage），
就从这里长：界面只调 lib 的接口，换存储方案时不用改界面。
